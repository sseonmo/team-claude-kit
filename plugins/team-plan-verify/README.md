# team-plan-verify

계획을 **네 관점으로 순차 검증**하는 스킬.

## 문제

플랜을 여러 번 검증해도 **같은 각도로만 보면 같은 것만 잡힌다.**

아키텍처 검증은 "있는 것이 잘 짜였나"를 본다. 그래서 **기능이 통째로 없는 것**은 끝까지 안 잡힌다.
그리고 검증을 거듭할수록 플랜은 무거워지기만 한다 — 앞선 검증이 추가한 것을 아무도 청소하지 않기 때문이다.

## 해결

렌즈 넷이 **서로의 영역을 침범하지 않고** 순서대로 돈다.

| 순서 | 렌즈 | 이 렌즈만 잡는 것 |
|---|---|---|
| 1 | 사용자 | 기능 누락, 사용자가 본류로 못 돌아오는 **종점**, 시스템은 성공인데 화면은 그대로인 **조용한 성공** |
| 2 | 엔지니어 | 이 문서대로 짜면 깨지는 지점. 결론이 맞아도 **근거가 틀렸으면** 지적한다 |
| 3 | 실패·보안 | 없으면 무엇이 뚫리거나 죽는가. 부분 실패·멱등성·잘못된 값이 성공으로 처리되는 경로 |
| 4 | 과잉 | **앞선 셋이 추가한 것**을 재심사한다. 아무것도 덜어내지 못하면 이 라운드는 실패다 |

순서를 바꾸지 않는다. 1이 기능 누락을 먼저 찾아야 2가 헛돌지 않고, 4는 2·3이 넣은 것을 청소하므로
마지막이어야 한다. 각 렌즈에는 **앞선 렌즈들의 결정 표를 누적해서** 넘긴다 — 직전 것만 넘기면
4의 자기검수가 이름만 남는다.

## 사용법

```
/plan-verify                    # 대상을 스스로 찾고 규모를 판정
/plan-verify docs/design.md     # 문서 지정
/plan-verify feature            # 규모 강제 (full | feature)
```

**대상이 파일이 아니어도 된다.** 플래닝이 끝난 직후가 검증하기 가장 좋은 시점인데 그때는 문서가 없다.
대화로만 합의한 계획이면 먼저 한 벌로 정리해 고정한 뒤 검증에 들어간다.

## 규모 판정

세 신호(대상 범위 · 새 외부 서비스 · 새 사용자 진입 경로)를 보고 **FULL** / **FEATURE** 를 정한다.
3개가 한 방향이면 묻지 않고 자동 판정하고, 1~2개만 걸리면 판정을 보여주고 묻는다.

- **FULL** — 시나리오 전수·상태 머신·권한 매트릭스. 교차 대조 실행
- **FEATURE** — 시나리오 목록만. 교차 대조 생략 (기능 하나에는 대조할 독립 2안이 성립하지 않는다)

## 교차 대조 (FULL 기본)

반영이 끝난 최종본이 A안이다. `codex` 에게 **요구사항만** 주고 독립 설계(B안)를 받아 대조한다.
아키텍처·데이터 모델·ADR 은 넘기지 않는다 — 넘기면 베낀 답이 와서 대조가 무의미해진다.

목적은 좋은 안을 고르는 것이 아니라 **A안이 통째로 빠뜨린 것**을 찾는 것이다. 뽑는 것은 둘뿐이다.

- **갈림** — A와 B가 배타적으로 다른 답을 낸 지점
- **공백** — 둘 다 정하지 않았거나, B가 "물어야 한다"고 짚은 것을 A도 안 정한 지점

`codex` 가 PATH 에 없거나 인증이 없으면 **건너뛰고 그 사실을 원인과 함께 보고한다.**
직접 B안을 만들지 않는다 — 같은 모델이 만든 B안은 A안과 사각지대가 상관되어 그 층을 못 채운다.

## 설계 원칙

- **렌즈 실행 중에는 파일을 쓰지 않는다.** 검증 대상도, 렌즈의 산출물도. 발견을 모아 반영 단계에서 일괄 적용한다.
  렌즈마다 편집하면 호출 수가 10배가 되고 비용의 대부분은 편집에서 나온다
- **"검증해줘"는 문서를 고쳐달라는 뜻이 아니다.** 적용할 목록을 먼저 보여주고 승인받은 뒤에 파일에 손댄다
- **통과 목록과 "확인하지 못한 것"을 반드시 남긴다.** 발견만 나열하면 무엇을 안 봤는지 알 수 없다
- **커밋·푸시하지 않는다** (사용자 지시 전용)

## 결정 권한

기준은 "대안이 열등한가, 다른가"다.

- **자동** — 방어 장치, 데이터 정합성, 사실 오류(틀린 근거·문서 간 모순·없는 참조)
- **질문** — 제품 방향, 숫자를 정해야 하는 것(보관 기간·한도), 구현 비용과 이탈의 저울질

"자동"은 묻지 않고 **결정 표에 확정으로 올린다**는 뜻이지, 묻지 않고 파일을 고친다는 뜻이 아니다.

## 의존성

없음. `codex` 는 있으면 교차 대조에 쓰고 없으면 건너뛴다.
