# team-security-scan

리포 전체를 **OWASP Top 10:2025** 열 개 항목으로 감사하고, 검증을 통과한 발견만 담은
단일 파일 HTML 대시보드를 남긴다. 언어·스택 무관.

## 구성

| 종류 | 이름 |
|---|---|
| Skill | `owasp-scan` |

## 쓰는 법

```
/owasp-scan
```

또는 "이 레포 보안 점검해줘", "릴리스 전에 취약점 스캔", "OWASP 로 감사해줘" 처럼 말해도 걸린다.

**코드는 고치지 않는다.** 산출물은 리포트다. 수정은 스캔을 끝낸 뒤 별도 작업으로 한다 —
스캔과 수정을 섞으면 감사 결과를 믿을 수 없다.

## 절차

1. **정찰** — 언어·프레임워크·진입점·인증 방식·데이터 접근 계층을 파악해 공통 컨텍스트를 만든다
2. **도구 패스** — 검증된 명령만 돌린다. 못 돌린 도구는 이유와 함께 `skipped` 로 기록
3. **항목별 팬아웃** — A01~A10 에 서브에이전트 하나씩, 열 개를 한 번에
4. **취합과 검증** — 도구 결과의 사각지대를 메우고, `critical`·`high` 는 검증 에이전트가 반박
5. **리포트** — `.security/owasp-<날짜>.html` 조립

## 이 스킬이 막는 실패

전부 스킬 없이 스캔했을 때 **실제로 나온** 것들이다.

| 실패 | 막는 방법 |
|---|---|
| 2021 카테고리 번호로 보고 | 2021→2025 변환표를 참조 문서로 강제. Injection 은 A03 이 아니라 **A05**, 설정은 A05 가 아니라 **A02** |
| 있어야 할 것이 없는 걸 못 봄 | 항목마다 **부재 점검**을 별도 지시. 완전히 놓친 3건이 전부 이 유형이었다 (로깅 전무·빈 `catch` fail-open·`DEBUG=true`) |
| 겹치는 항목을 서로 미룸 | semgrep 의 CSRF 경고를 A01·A02·A07 이 모두 "남의 소관"으로 넘겼다. 취합 단계에서 미반영 도구 결과를 직접 훑는다 |
| 의존성 CVE 를 놓침 | 코드 정독은 "오래된 버전이 있다"에 그쳤고 도구는 같은 리포에서 CVE 13건을 버전까지 특정했다 |
| 리포트가 빈 화면 | 코드 조각을 JSON 에 손으로 쓰면 따옴표·줄바꿈이 깨진다. `file`+`line` 만 주고 **스크립트가 디스크에서 읽는다** |
| 오탐을 그대로 올림 | 시크릿 스캐너 실측 3건 중 2건이 오탐이었다. `critical`·`high` 는 반박 검증을 통과한 것만 |
| "전부 확인했다" 고 단언 | 미실행 도구와 `notChecked` 를 리포트에 배너로 남긴다 |

> **도구가 조용한 영역은 깨끗한 영역이 아니다.** 실측 커버리지는 도구 최선 조합으로도 약 3분의 1이다.

## 산출물

`.security/owasp-<YYYY-MM-DD>.html` — 단일 파일 대시보드. 심각도 분포, 항목별 발견,
코드 조각, 미실행 도구 배너를 담는다. 외부 의존 없음.

결과 JSON 은 리포 밖 임시 경로에 쓰고 리포에 남기지 않는다. `.gitignore` 에 `.security/` 가
없으면 한 줄 추가한다.

## 구성 파일

| 파일 | 내용 |
|---|---|
| `skills/owasp-scan/references/owasp-2025.md` | 2025 목록, 2021→2025 변환표, 항목별 존재·부재 점검, 중복 배정 규칙 |
| `skills/owasp-scan/references/tools.md` | 검증된 실행 명령, 도구별 실측 커버리지, 제외 경로 |
| `skills/owasp-scan/references/finding-schema.md` | 발견 JSON 스키마, `scenario` 작성 규칙, 심각도 기준 |
| `skills/owasp-scan/scripts/build_report.py` | 결과 JSON → 대시보드 HTML 조립. 스키마 검사 + 코드 조각 읽기 |
| `skills/owasp-scan/assets/report.html` | 대시보드 템플릿 |

## 의존성

없음. 조립 스크립트는 **Python 3 stdlib only**.

2단계의 정적 분석·의존성 스캔 도구는 있으면 쓰고 없으면 건너뛴다 — 설치를 강요하지 않고,
못 돌린 것은 리포트에 남는다.

## 테스트

python3 plugins/team-security-scan/skills/owasp-scan/scripts/test_build_report.py
